# Media stack — Sonarr + Whisparr + qBittorrent + Prowlarr + Jellyfin

Sonarr follows series (anime). Whisparr v3 follows movies. Both send grabs to the same qBittorrent and can be streamed from Jellyfin.

## Services

| Service | Port | Purpose |
|---|---|---|
| Sonarr | 8989 | Series manager — monitors indexers, triggers downloads, organises files |
| Whisparr | 6969 | Movie manager (v3) — same job as Sonarr, for movies |
| qBittorrent | 8080 | Torrent download client |
| Prowlarr | 9696 | Indexer manager — syncs sources to Sonarr and Whisparr |
| Jellyfin | 8096 | Media server for streaming |

## VPN

Sonarr, Whisparr, Prowlarr and qBittorrent run inside the `vpn` stack's network namespace (`network_mode: container:vpn`), so their internet traffic exits through Mullvad. Jellyfin does not. Start `vpn` first, and re-create this stack (`docker compose up -d --force-recreate`) whenever the `vpn` container is re-created. The apps still reach each other by the same hostnames and keep the same Caddy routes; see `vpn/README.md`.

## Directory layout

```
sonarr/
├── docker-compose.yml
├── config/             # Runtime-generated by services, not committed
│   ├── sonarr/
│   ├── whisparr/
│   ├── qbittorrent/
│   ├── prowlarr/
│   └── jellyfin/
└── data/               # Downloads and media, not committed
    ├── downloads/       # Active torrents (auto-cleared after 7 days)
    └── media/
        ├── anime/       # Sonarr library
        └── whisparr/    # Whisparr library
```

Both `config/` and `data/` are created automatically on first boot — nothing to create manually.

To store the data folder outside this repository, set `DATA_DIR` before starting the stack:

```bash
DATA_DIR=/path/to/external/data docker compose up -d
```

You can also put it in a local `.env` file next to `docker-compose.yml`:

```env
DATA_DIR=/path/to/external/data
```

## Start

```bash
docker compose up -d
```

## One-time setup (first boot)

### 1. qBittorrent

Open http://localhost:8080

Get the generated password from logs:
```bash
docker logs qbittorrent | grep -i password
```

Log in, then go to **Tools → Options**:

- **Downloads** → Default Save Path: `/data/downloads`
- **BitTorrent** → Seeding limits:
  - When seeding time reaches: `10080` min (7 days) ✓ *(already in config)*
  - Action: `Remove torrent and its files` ✓ *(already in config)*

> The seeding limits are already pre-configured in `config/qbittorrent/`. This step is just to verify.

### 2. Prowlarr → Sonarr and Whisparr

Open http://localhost:9696

- **Settings → Apps → Add → Sonarr**
  - Sonarr URL: `http://sonarr:8989`
  - API Key: copy from Sonarr → Settings → General
- **Settings → Apps → Add → Whisparr**
  - Whisparr URL: `http://whisparr:6969`
  - API Key: copy from Whisparr → Settings → General

Prowlarr reaches both by the names above because they share the VPN container's network. Choose which apps each indexer syncs to.

### 3. Add Nyaa.si indexer in Prowlarr

- **Indexers → Add** → search `Nyaa` → add **Nyaa.si**
- Prowlarr auto-syncs it to Sonarr — no manual indexer config needed in Sonarr

### 4. Sonarr download client

Open http://localhost:8989 → **Settings → Download Clients → Add → qBittorrent**

- Host: `qbittorrent`
- Port: `8080`
- Username / Password: same as step 1
- Category: `sonarr`

### 5. Whisparr download client and root folder

Open Whisparr → **Settings → Download Clients → Add → qBittorrent**

- Host: `qbittorrent`
- Port: `8080`
- Username / Password: same as step 1
- Category: `whisparr`

**Settings → Media Management → Root Folders → Add**: `/data/media/whisparr`

Use a different category from Sonarr so the two apps don't import each other's downloads.

### 6. Sonarr root folder

**Settings → Media Management → Root Folders → Add**: `/data/media/anime`

### 7. Prefer h.265 releases (Custom Format)

**Settings → Custom Formats → Add**:
- Name: `x265 / HEVC`
- Condition: Release Title → regex `(x265|HEVC|H\.265)`

**Settings → Quality Profiles → your profile**:
- Score `x265 / HEVC`: `+10`
- Enable **Upgrades Allowed** so Sonarr replaces h.264 grabs when h.265 appears

### 8. Jellyfin

Open http://localhost:8096 and complete the setup wizard:

- Add media library → **Shows** → path: `/media/anime`
- Add media library → **Movies** → path: `/media/whisparr`
- For better anime metadata: Dashboard → Plugins → Catalog → install **AniDB**

## How it works

```
Indexers
   ↓
Prowlarr  ──(auto-sync)──→  Sonarr / Whisparr  ──→  qBittorrent
                                                        ↓
                                              data/downloads/
                                                        ↓  (hardlink, no copy)
                                    data/media/anime/   data/media/whisparr/
                                                        ↓
                                                    Jellyfin
```

Files in `data/downloads` and the library folders are **hardlinks** — the data is stored once on disk. After 7 days qBittorrent removes its entry and the downloads copy; the Jellyfin library copy remains untouched. Sonarr and Whisparr only hardlink into their own root folder when qBittorrent categories stay separate (`sonarr` and `whisparr`).
